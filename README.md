# EdgeBus Web Connection (Troubleshooting) Monitoring Tool

На теперішній час, майже в кожній країні світу, регулятори створюють обмеження на використання програмного забезпечення чутливого до локального законодавства. В свою чергу, оператори мереж, блокуючи чутливе програмне забезпечення, як побічний ефект, можуть блокувати Ваше програмне забезпечення яке не підпадає під регуляцію.

**EdgeBus Web Connection Monitoring** - допоможе Вам з'ясувати наявність проблем в з'єднанні руками недосвідченого користувача.

## How it works / Як це працює?

1. Технічний спеціаліст відвідує адмінську частину Web-застосунку для налаштувань сценарію сканування/тестування результатом чого формує унікальний URL
1. Технічний спеціаліст спонукає користувача відкрити попередньо сформований URL в браузері на "проблемному" пристрої
1. Клієнтська частина Web-застосунку проводить серію сканування/тестування
1. Клієнтська частина Web-застосунку інформує про результати:
   - безпосередньо реальному часі в адмінську частину Web-застосунку (браузер технічного спеціаліста)
   - формує QR-код з результатами для оффлайн режиму
1. Опційно, користувач пересилає скріншот з результатами технічному спеціалісту
